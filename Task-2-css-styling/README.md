# Task 2 - CSS Styling & Layout Techniques

This project is a simple food delivery landing page created for Task 2 of the internship.

## Features

- Styled navbar and hero section
- Reusable buttons and cards
- Flexbox layout for sections and cards
- Hover effects and transitions
- Pricing table
- Contact links

## Tools Used

- HTML5
- CSS3
- VS Code
- Chrome DevTools

## Task Objectives Covered

- Applied CSS for fonts, colors, spacing, and buttons
- Created layouts using Flexbox
- Built reusable UI components like cards and navbar
- Added hover effects and transitions
