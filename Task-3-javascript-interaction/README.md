# Task 3 - JavaScript Logic for User Interaction

This project is a simple food order form created for Task 3 of the internship.

## Features

- Form submission handled with JavaScript
- Validation for name, phone number, meal selection, and address
- Error messages shown below the fields
- Dynamic order summary displayed on the page
- Simple and clean CSS styling

## Tools Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Chrome DevTools

## Task Objectives Covered

- Handled form submissions using JavaScript
- Validated user inputs and displayed error messages
- Dynamically updated content on the page
