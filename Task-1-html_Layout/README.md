# Task 1 - Simple Resume Page

This project is a simple resume-style webpage created for the Web Development Internship task.

## Features

- Semantic HTML structure using `header`, `nav`, `main`, `section`, `article`, and `footer`
- Profile summary with image
- Skills and learning goals
- Education and internship table
- Contact links
- Contact links
