# Vautech Internship - Web Development

This repository contains the web development tasks completed during the Vautech internship. The work covers core frontend concepts including HTML structure, CSS styling, JavaScript interactivity, responsive design, and React development.

## Completed Tasks

### 1. HTML Layout
- Built a simple resume-style webpage
- Used semantic HTML elements for clean structure
- Added profile, skills, education, and contact sections

### 2. CSS Styling
- Created a food delivery landing page
- Designed navbar, hero section, buttons, and cards
- Used Flexbox, hover effects, and transitions

### 3. JavaScript Interaction
- Built a food order form with validation
- Displayed error messages for incorrect input
- Generated a dynamic order summary on the page

### 4. Responsive Design
- Developed a responsive landing page for desktop and mobile
- Used Flexbox, Grid, and media queries
- Kept the structure ready for deployment

### 5. React Interface
- Built a movie watchlist app using React and Vite
- Added features to add, remove, and mark movies as watched
- Stored movie data with localStorage
