# Task 5 - Movie Watchlist App

This is a simple React project built for Task 5 of the internship.

## Features

- Add a movie with title, description, and genres
- Show and hide the add movie form
- Mark a movie as watched or not watched
- Remove a movie from the list
- Save movie data in localStorage

## Tools Used

- React
- Vite
- SCSS

## Concepts Used

- Components
- `useState`
- Context API
- Event handling
- Conditional rendering
- localStorage
