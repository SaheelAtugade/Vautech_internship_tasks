# Task 4 - Responsive Web Design & Deployment

This project is a simple responsive landing page created for Task 4 of the internship.

## Features

- Responsive layout for desktop and mobile
- Flexbox used in header, hero section, and plan cards
- Grid used in the features section
- Clean spacing, colors, and simple button styling
- Contact links for deployment-ready structure

## Tools Used

- HTML5
- CSS3
- VS Code
- Chrome DevTools
- GitHub

## Task Objectives Covered

- Used media queries for responsiveness
- Applied Flexbox and Grid for layout
- Prepared the folder to deploy with GitHub Pages
- Maintained a clean structure for version control
